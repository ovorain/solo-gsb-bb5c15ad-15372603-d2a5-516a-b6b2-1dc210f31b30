# SRT 字幕时间轴校准工具

一款**完全本地运行**的字幕时间轴校准 Web 工具：导入 SRT 字幕，通过若干“校准锚点”把原始时间映射到目标时间，实时重算全部字幕的起止时间，校验通过后导出序号与文本不变的新 SRT。

基于 **React 18 + TypeScript + Vite**，纯前端处理，文件不会上传到任何服务器。

## 一条命令启动（Docker）

```bash
docker compose up -d --build
```

启动后访问：

> **http://localhost:8080**

- 容器内端口：`80`（Nginx 托管静态文件）
- 宿主机端口：`8080`（在 `docker-compose.yml` 的 `ports` 中修改，例如 `"9000:80"`）

停止服务：

```bash
docker compose down
```

## 本地开发 / 不用 Docker

要求 Node.js 18+（推荐 20）。

```bash
npm install
npm run dev
```

访问 Vite 开发服务器：**http://localhost:5173**

生产构建与本地预览：

```bash
npm run build      # 类型检查 + 产物输出到 dist/
npm run preview    # http://localhost:4173
```

## 使用说明

1. 点击 **导入 SRT**，或将 `.srt` 文件直接拖入页面；也可点击 **载入示例** 快速体验。
2. 在任意字幕行点击 **＋ 设为锚点**，锚点绑定该字幕的**原始起始时间**，再把目标起始时间改成期望的值（格式 `HH:MM:SS,mmm`，回车提交、Esc 撤销）。
3. 表格实时显示每条字幕的原始起止时间、偏移量、校准后起止时间与字幕文本，便于对照。
4. 可随时 **撤销** 最近一次锚点操作（新增 / 删除 / 编辑目标时间 / 应用方案均可撤销）。
5. 全部问题清零后点击 **导出新 SRT**，下载得到 `<原文件名>.aligned.srt`。

### 锚点方案：一次校准，复用到修订版

字幕出了修订版（时间轴整体变化、文本基本不变）时，不必重新逐条设锚点——把当前校准导出为**锚点方案**（JSON），再导入到新文件即可自动重建锚点：

1. 校准完成后点击 **导出方案**，下载得到 `<原文件名>.anchors.json`。
2. 导入修订版 SRT 后点击 **导入方案**，选择该 JSON 文件。
3. 界面弹出**匹配预览**，逐条列出每个锚点的匹配结果；确认后点击 **应用 N 个有效锚点**（或取消）。
4. 应用以全部有效项**替换当前锚点**，作为**一次操作**进入撤销历史（可一键撤销）；**字幕文本不会被修改**。

**方案文件格式**（带版本号，未知版本或畸形字段会被拒绝并在界面提示原因）：

```json
{
  "version": 1,
  "anchors": [
    { "source": 1000, "target": 3000, "text": "第一条字幕的规范化文本" }
  ]
}
```

- `source` / `target`：锚点的原始 / 目标时间（毫秒，非负）。
- `text`：锚点对应字幕的**规范化文本**——仅去除首尾空白、连续空白合并为单个空格，不做其它改写。

**导入时的匹配规则**（逐条判定，互不影响）：

| 结果 | 条件 |
| --- | --- |
| 直接匹配 | 当前字幕中存在**原始时间与规范化文本均相同**的条目 |
| 迁移 | 未直接匹配，但该规范化文本在全文中**恰好出现一次**，迁移到该字幕的起始时间 |
| 冲突（不应用） | 文本**缺失**、文本**重复**（出现多次无法唯一迁移），或应用后会**破坏锚点顺序**（原始时间 / 目标时间无法保持严格递增） |

冲突项在预览中标红并注明原因，确认应用时自动跳过；只有全部有效项会进入锚点列表。

### 校准规则

| 锚点数量 | 映射方式 |
| --- | --- |
| 0 个 | 保留全部原始时间 |
| 1 个 | 以该锚点的 `目标时间 − 原始时间` 为偏移，整体平移所有字幕 |
| 多个 | 相邻锚点之间做分段线性插值；首段之前、末段之后分别沿最近区段的**斜率外推** |

### 合法性约束

- 锚点的**原始时间**严格递增（由字幕原始起始时间唯一确定，同一原始时间不可重复设锚点）。
- 锚点的**目标时间**也必须两两严格递增。
- 非法的目标时间编辑（格式错误、为负、破坏递增顺序）**不会生效**，输入框立即回退到上一个合法值并提示原因。

### 错误标红与导出拦截

映射结果若出现以下情况，相关行会整行标红并注明原因：

- **负时间**：校准后的起始或结束时间小于 0（常见于首段斜率外推）。
- **非正时长**：校准后结束时间 ≤ 起始时间。
- **重叠**：校准后与相邻字幕的时间轴发生交叠。

只要存在任意一条问题字幕，**导出按钮禁用**；可使用顶部“仅错误”筛选快速定位。

```
├── Dockerfile              # 多阶段构建：Node 构建 → Nginx 托管
├── docker-compose.yml      # 一条命令启动，宿主端口 8080
├── nginx.conf              # SPA 回退与静态资源缓存
├── index.html
├── src
│   ├── main.tsx
│   ├── App.tsx             # 导入 / 锚点操作 / 撤销 / 方案导入导出 / 导出与状态编排
│   ├── styles.css
│   ├── sample.ts           # 内置示例 SRT
│   ├── components
│   │   ├── CueTable.tsx        # 对照表（原始/偏移/校准后/锚点/状态）
│   │   ├── TargetTimeInput.tsx # 锚点目标时间行内编辑
│   │   └── PlanPreview.tsx     # 锚点方案导入预览（匹配/迁移/冲突）
│   └── lib
│       ├── time.ts     # SRT 时间 ⇄ 毫秒
│       ├── srt.ts      # SRT 解析与序列化
│       ├── anchor.ts   # 锚点构造、分段线性映射、错误校验
│       └── plan.ts     # 锚点方案：序列化/校验/匹配迁移
└── README.md
```

## SRT 兼容性

- 兼容 LF / CRLF、UTF-8 BOM、缺失序号块、点号或逗号毫秒分隔符。
- 时间码无法解析的块会被跳过并在导入提示中报告数量。
- 导出时序号文本与字幕文本（含多行与样式标签）原样保留，仅替换时间码。

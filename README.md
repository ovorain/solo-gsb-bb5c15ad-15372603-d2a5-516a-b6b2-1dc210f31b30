# SRT 字幕时间轴校准工具

一款**完全本地运行**的字幕时间轴校准 Web 工具：导入 SRT 字幕，通过若干“校准锚点”把原始时间映射到目标时间，实时重算全部字幕的起止时间，校验通过后导出序号与文本不变的新 SRT。

基于 **React 18 + TypeScript + Vite**，纯前端处理，文件不会上传到任何服务器。

## 一条命令启动（Docker）

```bash
docker compose up -d --build
```

启动后访问：

> **http://localhost:8080**

- 容器内端口：`80`（Nginx 托管静态文件）
- 宿主机端口：`8080`（在 `docker-compose.yml` 的 `ports` 中修改，例如 `"9000:80"`）

停止服务：

```bash
docker compose down
```

## 本地开发 / 不用 Docker

要求 Node.js 18+（推荐 20）。

```bash
npm install
npm run dev
```

访问 Vite 开发服务器：**http://localhost:5173**

生产构建与本地预览：

```bash
npm run build      # 类型检查 + 产物输出到 dist/
npm run preview    # http://localhost:4173
```

## 使用说明

1. 点击 **导入 SRT**，或将 `.srt` 文件直接拖入页面；也可点击 **载入示例** 快速体验。
2. 在任意字幕行点击 **＋ 设为锚点**，锚点绑定该字幕的**原始起始时间**，再把目标起始时间改成期望的值（格式 `HH:MM:SS,mmm`，回车提交、Esc 撤销）。
3. 表格实时显示每条字幕的原始起止时间、偏移量、校准后起止时间与字幕文本，便于对照。
4. 可随时 **撤销** 最近一次锚点操作（新增 / 删除 / 编辑目标时间均可撤销）。
5. 全部问题清零后点击 **导出新 SRT**，下载得到 `<原文件名>.aligned.srt`。

### 校准规则

| 锚点数量 | 映射方式 |
| --- | --- |
| 0 个 | 保留全部原始时间 |
| 1 个 | 以该锚点的 `目标时间 − 原始时间` 为偏移，整体平移所有字幕 |
| 多个 | 相邻锚点之间做分段线性插值；首段之前、末段之后分别沿最近区段的**斜率外推** |

### 合法性约束

- 锚点的**原始时间**严格递增（由字幕原始起始时间唯一确定，同一原始时间不可重复设锚点）。
- 锚点的**目标时间**也必须两两严格递增。
- 非法的目标时间编辑（格式错误、为负、破坏递增顺序）**不会生效**，输入框立即回退到上一个合法值并提示原因。

### 错误标红与导出拦截

映射结果若出现以下情况，相关行会整行标红并注明原因：

- **负时间**：校准后的起始或结束时间小于 0（常见于首段斜率外推）。
- **非正时长**：校准后结束时间 ≤ 起始时间。
- **重叠**：校准后与相邻字幕的时间轴发生交叠。

只要存在任意一条问题字幕，**导出按钮禁用**；可使用顶部“仅错误”筛选快速定位。

## 项目结构

```
├── Dockerfile              # 多阶段构建：Node 构建 → Nginx 托管
├── docker-compose.yml      # 一条命令启动，宿主端口 8080
├── nginx.conf              # SPA 回退与静态资源缓存
├── index.html
├── src
│   ├── main.tsx
│   ├── App.tsx             # 导入 / 锚点操作 / 撤销 / 导出与状态编排
│   ├── styles.css
│   ├── sample.ts           # 内置示例 SRT
│   ├── components
│   │   ├── CueTable.tsx        # 对照表（原始/偏移/校准后/锚点/状态）
│   │   └── TargetTimeInput.tsx # 锚点目标时间行内编辑
│   └── lib
│       ├── time.ts     # SRT 时间 ⇄ 毫秒
│       ├── srt.ts      # SRT 解析与序列化
│       └── anchor.ts   # 锚点构造、分段线性映射、错误校验
└── README.md
```

## SRT 兼容性

- 兼容 LF / CRLF、UTF-8 BOM、缺失序号块、点号或逗号毫秒分隔符。
- 时间码无法解析的块会被跳过并在导入提示中报告数量。
- 导出时序号文本与字幕文本（含多行与样式标签）原样保留，仅替换时间码。
